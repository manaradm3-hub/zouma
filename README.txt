# Zoüma™ Website

موقع صفحة واحدة لبراند Zoüma™.

## رفعه على GitHub Pages
1. أنشئي Repository جديد على GitHub.
2. ارفعي `index.html` ومجلد `assets` كما هما.
3. من Settings → Pages اختاري Deploy from a branch.
4. اختاري Branch: main و Folder: / (root).
5. احفظي وانتظري ظهور رابط الموقع.

لا تغيري أسماء ملفات الصور داخل مجلد assets إلا لو عدلتِ المسارات داخل index.html.
